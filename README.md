# Rob Williams

**I make AI agents do real VFX work - Nuke, Houdini, Unreal, and ComfyUI, wired into production.**

Lead Visdev Artist at Framestore, Los Angeles. Fourteen years in VFX:
compositing first, then real-time and generative pipelines. These days I
build the tooling that lets Claude-powered agents build node graphs in Nuke,
drive Houdini and Unreal, and run generative models as production steps -
then I use that tooling on real commercial work, every day.

## vfx-agent-toolkit

**[vfx-agent-toolkit](https://github.com/sideshowroberto/vfx-agent-toolkit)** -
Claude Code plugins and MCP connectors for VFX production. Ten plugins
covering Nuke, Houdini, Unreal, Blender, ComfyUI, Maya, and generative
services, with one-clone connector installs. MIT licensed.

The design split, in one line: **skills teach the agent the craft;
connectors give it hands in the running applications.**
