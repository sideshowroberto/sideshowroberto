## vfx-agent-toolkit

**[vfx-agent-toolkit](https://github.com/sideshowroberto/vfx-agent-toolkit)** -
Claude Code plugins and MCP connectors for VFX production. Ten plugins
covering Nuke, Houdini, Unreal, Blender, ComfyUI, Maya, and generative
services, with one-clone connector installs. MIT licensed.

The design split, in one line: **skills teach the agent the craft;
connectors give it hands in the running applications.**
