# Rob Williams

**I make AI agents do real VFX work - Nuke, Houdini, Unreal, and ComfyUI, wired into production.**

Lead Visdev Artist at Framestore, Los Angeles. Fourteen years in VFX:
compositing first, then real-time and generative pipelines. My day-to-day
is agentic production work on real commercial shots:

- **Autonomous asset generation across DCCs and hosted models.** Agents
  that carry a shot from previs to comp-ready elements: render control
  passes (clay, wireframe, depth, cryptomatte) out of Blender, generate
  photoreal anchor frames and video through ComfyUI and hosted generative
  services, QC every result against the plate with sub-pixel camera-drift
  measurement, and deliver finished elements into Nuke - one agent
  coordinating every application in the chain.
- **Complex scene work by delegation.** Agent-built crowd systems with
  ~16,000 instanced, animation-varied characters, batch retargeting of
  motion libraries across dozens of rigs, and multi-shot master scenes
  with per-shot cameras, caches, and render configs - the kind of scene
  wrangling that used to eat days.
- **Custom tools on demand.** When a shot needs a tool that doesn't
  exist - a Nuke light-rig gizmo driven by baked 3D axes, batch pass
  renderers, per-shot workflow generators - the agent and I build it in
  the session, and the keepers ship in the toolkit below.

## vfx-agent-toolkit

**[vfx-agent-toolkit](https://github.com/sideshowroberto/vfx-agent-toolkit)** -
Claude Code plugins and MCP connectors for VFX production. Ten plugins
covering Nuke, Houdini, Unreal, Blender, ComfyUI, Maya, and generative
services, with one-clone connector installs. MIT licensed.

The design split, in one line: **skills teach the agent the craft;
connectors give it hands in the running applications.**
